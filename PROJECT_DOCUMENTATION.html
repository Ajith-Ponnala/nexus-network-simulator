NEXUS — Network Systems Lab

Interactive Computer Networks Protocol Simulator & Pedagogical Workbench
React 19.0 Vite 8.0 Vitest (45/45 Tests Passed) Computer Networks Lab
Project Overview: NEXUS is an interactive network protocol simulation suite demonstrating Dijkstra Shortest-Path Routing (Network Layer), Frame Encapsulation (Data Link Layer), CRC Polynomial Division (Physical Layer Error Detection), and End-to-End Multi-Hop Message Transmission.

1. Core Features & Architecture

Physical Topology Editor

  • Freely Draggable Routers: Interactive drag-and-drop node positioning across the SVG canvas with live coordinate updates.
  • Auto-Fitting ViewBox: Dynamic vector scaling ensures routers R1–R6, link costs, and badges are 100% visible on any screen size.
  • Interactive Link Failure Toggle: Click any link cost badge to toggle the link between ON (active) and OFF (severed). Dijkstra automatically recalculates backup routes.
  • High-Visibility Roles: Source router highlighted in emerald green with SRC badge; Destination router highlighted in vibrant orange with DEST and pulsing radar ring.

Protocol Sandbox (Framing & CRC)

  • Character Count Framing: Frame size prefixing and length extraction.
  • Byte Stuffing: Flag bytes (0x7E) and Escape bytes (0x7D) with automatic byte escaping.
  • Bit Stuffing (HDLC): Zero-bit insertion after five consecutive 1s (0111110 pattern).
  • Modulo-2 CRC Binary Division: Modulo-2 binary long division with bitwise XOR math.
  • Polynomial Presets: CRC-3 (1011), CRC-4 (10011), CRC-8, CRC-16, and custom binary divisors.
  • Controlled Noise Injection: Interactive bit flipper demonstrating non-zero remainder error detection.
  • Bitwise XOR Trace Table: Collapsible step-by-step division trace.

Transmission Simulator

  • End-to-End Multi-Hop Orchestration: Packet chunking, hop-by-hop framing, CRC generation, link transit, and destination reassembly.
  • Live In-Flight HUD Banner: Real-time hop banner showing active router link, packet index, and wire noise status.
  • 1-Click Guided Scenarios: Clean Transmission, CRC Catches Noise (Drop at R2), Multi-Packet Chunking, and Flag Collision Escaping.
  • Playback Controls: Play, Pause, Step Forward, Step Backward, Reset, Timeline Scrubber, and Speed controls (0.5x, 1.0x, 2.0x).
  • Categorized Event Log: Filter tabs (All, Hops, Drops & Errors, Verified) and visual codeword bit-flip chip highlights.
  • Reassembled Payload Validation: Reconstructs message payload at destination and verifies 100% data integrity.

2. Quick Start & Execution

To run this project on any system with Node.js installed:

# 1. Unzip the project folder and open a terminal inside it
cd nexus-network-simulator

# 2. Install dependencies
npm install

# 3. Launch local development server
npm run dev

# 4. Run automated unit tests
npm run test
